# Reference / legacy files (not part of the app)

These HTML files document how the Deep Links Generator's logic was originally derived. They are
**reference-only** — they are not routed, not deployed, and not loaded by the live tool. The live
app is `../index.html`.

- `Deeplinks.html` — the former canonical working copy; `../index.html` is now the single source.
- `hdfc_utm_link_builder.html` — original reference for the HDFC `extra_param` JSON logic.
- `SBI Deeplinks.html` — legacy standalone (pre-merge).
- `Deeplinks for HDFC IR, IRMTF, Sky.html` — legacy standalone (pre-merge).
- `workingDeeplinks.html` — earlier working draft.

See `../ENGINEERING.md` for the full engineering guide and the add-a-broker recipe.
